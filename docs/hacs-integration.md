# audioctl в Home Assistant

Интеграция ставится через HACS как custom integration и читает MQTT, который публикует само приложение audioctl. Своего брокера у неё нет: нужен уже настроенный MQTT в Home Assistant.

Не включайте одновременно MQTT discovery в audioctl и эту интеграцию. Оба создают одни и те же сущности, и каждый ползунок появится дважды. Discovery удобен, если интеграцию ставить не хочется. Интеграция удобнее, когда устройств много: она не засоряет discovery-топики и понимает подключение и отключение устройств.

## Установка

1. В HACS добавьте этот репозиторий как custom repository типа Integration.
2. Установите audioctl и перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → audioctl.
4. Базовая тема по умолчанию `audioctl`. Идентификатор узла оставьте пустым, чтобы видеть все компьютеры, или укажите его, если на одном брокере их несколько. Узел — это имя компьютера или значение `node_id` в настройках MQTT приложения.

В приложении MQTT должен быть включён, а галка Home Assistant MQTT discovery выключена.

## Что появляется

На компьютере:

- выбор устройства вывода и микрофона;
- текстовое поле команды, тот же язык, что в трее и CLI;
- кнопка обновления списка устройств.

На каждом устройстве:

- громкость 0–100;
- переключатель mute;
- кнопка «сделать основным».

Скрытые в audioctl устройства в MQTT не публикуются.

## Темы

`<base>` — это `<базовая тема>/<узел>`, например `audioctl/desktop`.

| Тема | Кто пишет | Что внутри |
| --- | --- | --- |
| `<base>/status` | приложение, retained, LWT | `online` или `offline` |
| `<base>/info` | приложение, retained | имя, версия, текущие вывод и микрофон и списки вариантов |
| `<base>/<key>/info` | приложение, retained | описание устройства, громкость, mute и признак устройства по умолчанию. Пустое сообщение удаляет устройство |
| `<base>/<key>/state` | приложение, retained | то же состояние в виде, который читает MQTT discovery |
| `<base>/output/set`, `<base>/input/set` | Home Assistant | имя, ключ, `next` или `prev` |
| `<base>/<key>/volume/set` | Home Assistant | число 0–100 или `+5` / `-5` |
| `<base>/<key>/mute/set` | Home Assistant | `ON` или `OFF` |
| `<base>/<key>/default/set` | Home Assistant | любое сообщение делает устройство основным |
| `<base>/command` | Home Assistant | строка команды, например `o next` |
| `<base>/rescan` | Home Assistant | любое сообщение |

Интеграция подписана только на `<base>/+/status`, `<base>/+/info` и `<base>/+/+/info`. Громкость и mute она видит, потому что приложение заново публикует `info` при каждом изменении.
